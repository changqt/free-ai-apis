# Contributing

## How to Add an API

1. Fork this repo
2. Add the API to the correct category in `README.md`
3. Follow the existing table format
4. Submit a pull request

## Criteria

- **Must have a free tier** — no "free trial only" or "credit card required"
- **Must have an API** — not just a web UI
- **Must be functional** — actually works and responds
- **Must have documentation** — link to docs required

## Format

```markdown
| [API Name](https://url.com) | Brief description | Free tier details | `apiKey` or `None` | [Docs](https://docs.url.com) |
```

## Categories

If an API doesn't fit existing categories, propose a new one with at least 3 APIs.
